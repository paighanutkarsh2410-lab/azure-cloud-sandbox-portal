Cloud Sandbox

About The Platform

Automated Self-Service Cloud Sandbox Provisioning Platform

Project Overview

This platform provides a self-service interface where users can request isolated cloud sandbox environments. The application demonstrates DevOps automation concepts using Flask, Azure App Service, Blob Storage and Infrastructure as Code.

Flask Backend

Python based application handling requests, database operations and APIs.

Microsoft Azure

Application hosting using Azure App Service with deployment package stored in Blob Storage.

Automation

Designed for integration with Bicep, Terraform and CI/CD pipelines.
